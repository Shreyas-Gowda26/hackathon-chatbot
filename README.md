# 🤖 HackCulture AI Chatbot

An intelligent AI-powered chatbot built with FastAPI and Groq LLM that provides instant answers about hackathons. The chatbot uses natural language processing to answer questions about hackathon themes, registration, judging criteria, prizes, and more.

## 🌟 Features

- **🧠 AI-Powered Responses**: Uses Groq's LLaMA 3.3 70B model for intelligent, context-aware answers
- **💬 Multi-Turn Conversations**: Maintains conversation context for natural dialogue
- **📊 Comprehensive Information**: Answers questions about themes, registration, prizes, judging, mentors, and more
- **🎯 Real-Time Status**: Provides definitive answers about registration and hackathon status based on current date
- **🌐 RESTful API**: Clean, well-documented API with automatic Swagger documentation
- **📱 Beautiful UI**: Modern, responsive chat interface with markdown support
- **🔄 Bulk Import**: Import single or multiple hackathons efficiently
- **🚀 Production Ready**: Deployed on Render (backend) and Netlify (frontend)
